## 🔥 Lessons Learned the Hard Way

1. **Always pull before you push.** Trust me.
2. **Commit often.** Future you will thank present you.
3. **Write meaningful commit messages.** `"asdf"` is not a message.
4. **`.gitignore` is your best friend.** Don't commit `node_modules`. Ever.
5. **`git diff` before `git add`** — know what you're staging!

## 🧠 Fun Git Facts

> 💬 **Did you know?** Git was created by **Linus Torvalds** in just **10 days** in 2005, originally to manage the Linux kernel source code.

> 💬 **The name "Git"** — Linus jokingly said he named all his projects after himself. "Git" is British slang for a stupid or unpleasant person.

> 💬 **The HEAD** in Git isn't some horror movie reference — it just points to the current branch or commit you're on.
